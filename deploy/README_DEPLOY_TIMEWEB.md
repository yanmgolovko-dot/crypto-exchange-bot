# Деплой crypto-bot на Timeweb Cloud (Ubuntu 22.04)

## 0. Предварительно

- Аккаунт на timeweb.cloud.
- Приватный GitHub-репозиторий с проектом (например, `crypto-exchange-bot`).
- Локально всё работает: `python run.py` запускается, `/health` отвечает.

## 1. Создание сервера в панели Timeweb Cloud

1. Войдите в панель → **Облачные серверы** → **Создать**.
2. **ОС и ПО**: выберите чистую **Ubuntu 22.04** (не маркетплейс-образ — нужен полный контроль).
3. **Конфигурация**: минимум **1 vCPU / 1 ГБ RAM / 15 ГБ SSD**. Для SQLite и одного бота этого достаточно.
4. **Сеть**: включите **публичный IPv4**. Приватная сеть не нужна.
5. **Авторизация**: загрузите **SSH-ключ** (рекомендуется) или задайте пароль root.
   - Если ключа нет, создайте его: `ssh-keygen -t ed25519 -C "bot@timeweb"` и загрузите публичную часть.
6. **Дополнительно**: DDoS-защиту можно не включать.
7. Нажмите **Заказать** и запомните **IP-адрес** сервера.
